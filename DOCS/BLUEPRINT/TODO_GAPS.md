## Các điểm cần kiểm chứng runtime thêm
- Gesture nâng cao (long-press/swipe) ở từng màn hình chưa thể suy luận hết từ static scan.
- Một số animation tùy biến theo điều kiện runtime (thiết bị yếu/mạnh) cần benchmark thực tế.
- Edge case đa thiết bị thao tác cùng một record trong mạng chập chờn cần test stress.
- Một số màn hình expansion chưa có log usage đủ để xác định ưu tiên UX thực tế.
- Luồng in ấn đa loại máy in cần ma trận test theo thiết bị thật.
